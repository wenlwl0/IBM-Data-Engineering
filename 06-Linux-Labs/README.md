# 06 - Linux and Shell Scripting Labs

linux_informational_commands.sh
## Learning Objectives
* System and user information
* User and group identity info

linux_navigating_and_managing_files_and_directories.sh 
## Learning Objectives
* Get the location of your present working directory
* List the files and directories within a directory
* Create a new directory
* Change your present working directory
* Create a new file
* Search for and locate files
* Remove, rename, move, or copy a file
